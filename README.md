# ผังงาน Workload

ผังงานรูปแบบ Organization chart แสดงภาระงานของพนักงาน นับจากจำนวนโปรเจคที่แต่ละคนเข้าร่วม

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

เปิด http://localhost:3000

## หน้าจอ

- `/` ผังรวม ดูตามสังกัดหรือตามโปรเจค
- `/projects` สร้างโปรเจค
- `/projects/[id]` ผังของโปรเจค และค้นหาชื่อคนเพื่อเพิ่มเข้าทีม
- `/employees` เพิ่ม แก้ไข และลบพนักงาน

## ข้อมูล

ข้อมูลเก็บที่ `data/db.json` ซึ่งถูกสร้างอัตโนมัติและ commit ไว้ใน repo (แก้ข้อมูลแล้วต้อง commit เองจึงจะขึ้น GitHub)
เซิร์ฟเวอร์ที่รันต้องมีดิสก์ถาวรและเป็น instance เดียว (ไม่รองรับ serverless อย่าง Vercel)

เกณฑ์ระดับงานปรับได้ที่ `src/lib/workload.ts`
